# CS-350
CS-350 Emerging Systems and Architecture

Reflection

For this course, I selected two artifacts to add to my portfolio. These were the final Thermostat.py implementation and the state machine diagram. Together, these help represent my ability to design and implement software that can interact directly with hardware and manage system state. 

Summary of Project

The project focused on building a functional thermostat prototype using a Raspberry Pi 4. The system reads temperature data from an AHT20 sensor, controls LEDs and buttons through GPIO, displays information on a 16x2 LCD screen, and sends updates over UART. 

What I Did Well

I feel I did well in integrating multiple hardware components into one cohesive system. Managing the state machine, LED behavior, LCD updates, and UART communication all at once required organization, and I was proud of how clean and readable the final code ended up turning out. 

Where I Could Improve

One area I could improve is being able to code with more confidence. I ran into issues of second-guessing myself because I was unsure of how certain code actually worked, which also made debugging tougher as well. 

Tools and Resources Added to My Support Network

Throughout this course, I added several tools to my support network. These include the GPIOZero library, Adafruit's hardware libraries, and the Python statemachine package. I also became more comfortable using Github during this class for version control and documentation, which was pretty interesting and will help me in future courses and professional work after.
